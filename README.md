# Escola Castelo Encantado — site V2

Novo site da Escola Castelo Encantado (Casa Amarela, Recife/PE), feito pela Nick Gomes Marketing Digital.

Site estático: basta publicar a pasta inteira em qualquer hospedagem (Hostinger, GitHub Pages etc.). A página inicial é o `index.html`.

## O que tem no site

- Carrossel na primeira dobra com a **Black Friday das Fardas** (contador até 30/11/2026) e o destaque institucional
- Aviso de cookies e página de Política de Privacidade (LGPD)
- Tito, o assistente virtual, com respostas prontas sobre a escola
- Quiz da turma ideal e Quiz Verde
- Blog organizado por data e por tipo de postagem

## Estrutura

- `index.html` — o site inteiro
- `assets/` — fotos da escola
- `vendor/petite-vue.iife.js` — biblioteca petite-vue 0.4.1 (licença MIT, em `vendor/petite-vue-LICENSE.txt`)
